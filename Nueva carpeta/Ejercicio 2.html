Guia de Administracion de Sistemas

Bienvenido a esta guia básica de sistemas informaticos en red

1. Instalacion de un sistema operativo

Primero debes elegir el sistema operativo adecuado segun las necesidades del entorno

1.1 Requisitos previos

Verfica el hadware,la compatibilidad y realiza una copia de seguridad.

1.2 Proceso de instalación

Utiliza un medio de instalación(USB,DVD) y sigue los pasos del asistente.

2. Configuración de una red

Una vez instalado el sistema ,se debe configurar la red para permitir la conectividad.

2.2 Dirección IP y DNS

Configura una Ip estatica o Dinamica y define los servidores DNS

2.2 Pruebas de conectividad

Usa comandos como ping o traceroute para verficar la conexion.
